Dependencies

  • @aws-sdk/client-apigatewaymanagementapi
    AWS SDK v3 client for managing WebSocket connections via the API Gateway Management API.

  • @mapbox/geojsonhint
    Validates GeoJSON objects and returns descriptive error messages if the structure is invalid.

  • @sentinel-hub/sentinelhub-js
    JavaScript library for interacting with Sentinel Hub APIs for Earth Observation data access and processing.

  • @turf/turf
    Advanced geospatial analysis library written in JavaScript for processing GeoJSON data.

  • aws-sdk
    Official AWS SDK for JavaScript (v2) that allows interaction with AWS services.

  • dotenv
    Loads environment variables from a .env file into process.env.

  • jimp
    Image processing library written entirely in JavaScript with no native dependencies.

  • jsonwebtoken
    Implementation of JSON Web Tokens (JWT) for authentication and authorization in Node.js.

  • jwks-rsa
    A library to retrieve RSA signing keys from a JWKS (JSON Web Key Set) endpoint.

  • mongoose
    MongoDB object modeling tool designed to work in an asynchronous environment.
