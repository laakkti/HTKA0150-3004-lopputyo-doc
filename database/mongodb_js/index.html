mongodb.js

The mongodb.js module acts as an API for interacting with the MongoDB database. It uses the Mongoose library to define models and perform database operations.

This Node.js module includes models for images and dates, and establishes a connection to the database using the provided URI.

Functionality Overview

Database Connection

  • Establishes a connection to a MongoDB database using Mongoose.

Date Operations

  • saveDates: Saves new date entries if they don’t already exist.
  • insertManyDates: Inserts multiple date entries, skipping duplicates.
  • updateDates: Updates an existing date entry with new items.
  • deleteDates: Deletes a date entry based on its ID.
  • getDates: Retrieves date entries associated with a specific ID.
  • getAllDateSets: Retrieves all available date entries.

Image Operations

  • saveImage: Saves a new image entry to the database if it doesn't already exist. Returns true if successful, false otherwise.
  • getImage: Retrieves a specific image entry based on its ID, excluding certain fields.
  • getAllImages: Finds all image entries that match a given search pattern (case-insensitive), excluding specific fields from the result.
  • deleteImage: Deletes an image entry by ID and returns the result of the operation.

Error Handling

Each function includes error handling to gracefully manage exceptions during database operations.
